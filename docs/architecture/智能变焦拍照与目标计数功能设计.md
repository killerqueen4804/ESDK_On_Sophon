## 1. 功能概述

### 1.1 背景与需求

在无人机航线任务执行过程中，需要对地面目标（如斑海豹）进行实时检测和统计。当检测到目标群体时，需要：

1. **暂停航线** - 让无人机悬停在当前位置
2. **变焦拍照** - 对目标区域进行高倍率变焦拍摄，获取高清图像
3. **目标计数** - 使用追踪算法对目标进行去重计数，避免重复统计
4. **恢复航线** - 拍照完成后继续执行航线任务

### 1.2 应用场景

- **目标类型**: 斑海豹（开发测试阶段使用车辆）
- **飞行模式**: 等高航线飞行
- **拍摄视角**: 俯视角度，目标遮挡少
- **实时性要求**: 检测到目标后需要快速响应（< 2 秒）

### 1.3 设计目标

| 目标       | 描述                                          |
| ---------- | --------------------------------------------- |
| **准确性** | 通过 ByteTrack 追踪实现精确计数，避免重复统计 |
| **实时性** | 检测到目标群体后 2 秒内完成悬停和变焦         |
| **可靠性** | 完善的异常处理和状态恢复机制                  |
| **可配置** | 关键参数可通过配置文件调整                    |
| **可扩展** | 策略模式设计，便于后续添加其他拍照策略        |

## 3. 详细设计

### 3.1 ByteTracker 追踪模块

#### 3.1.1 模块职责

- 对检测结果进行帧间关联，为每个目标分配唯一 Track ID
- 维护目标状态（New → Tracked → Lost → Removed）
- 提供去重计数能力（统计不重复的 Track ID 数量）

#### 3.1.2 文件结构

#### 3.1.3 类设计

追踪器接口直接使用项目已有的 `DetectionBox` 类型（定义在 `IDetector.h`），无需额外转换：

```cpp
/**
 * @file ByteTracker.h
 * @brief ByteTrack 追踪器封装类
 *
 * 封装 sophon-demo 中的 ByteTrack 实现，直接使用项目检测结果类型
 */

#ifndef ESDK_SOPHON_VISION_TRACKER_BYTETRACKER_H_
#define ESDK_SOPHON_VISION_TRACKER_BYTETRACKER_H_

#include <memory>
#include <vector>
#include <set>
#include <opencv2/core.hpp>
#include "esdk_sophon/vision/IDetector.h"  // 使用项目已有的 DetectionBox

namespace esdk_sophon {
namespace vision {
namespace tracker {

/**
 * @brief 追踪目标 - 在 DetectionBox 基础上增加追踪信息
 *
 * 继承自 DetectionBox，复用已有的检测结果字段，
 * 并添加追踪特有的 trackId 和 isNew 字段
 */
struct TrackedObject : public DetectionBox {
    int trackId = -1;     ///< 唯一追踪 ID（由 ByteTrack 分配）
    bool isNew = false;   ///< 是否为新目标（首次出现）

    TrackedObject() = default;

    /**
     * @brief 从 DetectionBox 构造
     */
    explicit TrackedObject(const DetectionBox& box)
        : DetectionBox(box), trackId(-1), isNew(false) {}
};

/**
 * @brief ByteTracker 配置参数
 */
struct ByteTrackerConfig {
    float trackThresh = 0.5f;      ///< 高置信度阈值
    float matchThresh = 0.8f;      ///< 匹配阈值
    int frameRate = 30;            ///< 视频帧率
    int trackBuffer = 30;          ///< 追踪缓冲帧数（丢失后保持多少帧）
    int minBoxArea = 100;          ///< 最小目标面积
};

/**
 * @brief ByteTrack 追踪器封装类
 *
 * 使用示例：
 * @code
 * ByteTrackerConfig config;
 * ByteTracker tracker(config);
 *
 * // 检测
 * DetectionResult detResult = detector->detect(frame);
 *
 * // 追踪（直接传入检测结果的 boxes）
 * auto trackedObjects = tracker.update(detResult.boxes);
 * int uniqueCount = tracker.getUniqueCount();
 * @endcode
 */
class ByteTracker {
public:
    explicit ByteTracker(const ByteTrackerConfig& config);
    ~ByteTracker();

    /**
     * @brief 更新追踪状态
     * @param detections 当前帧的检测结果（直接使用 DetectionBox）
     * @return 追踪后的目标列表（包含 Track ID）
     */
    std::vector<TrackedObject> update(const std::vector<DetectionBox>& detections);

    /**
     * @brief 获取不重复目标总数
     * @return 从任务开始到现在出现过的不重复目标数量
     */
    int getUniqueCount() const;

    /**
     * @brief 获取当前活跃目标数
     * @return 当前帧中正在追踪的目标数量
     */
    int getActiveCount() const;

    /**
     * @brief 重置追踪器状态
     */
    void reset();

private:
    class Impl;  // Pimpl 模式，隐藏 ByteTrack 实现细节
    std::unique_ptr<Impl> impl_;

    std::set<int> uniqueTrackIds_;  ///< 记录所有出现过的 Track ID
};

}  // namespace tracker
}  // namespace vision
}  // namespace esdk_sophon

#endif  // ESDK_SOPHON_VISION_TRACKER_BYTETRACKER_H_
```

#### 3.1.4 内部实现（Pimpl）

在 `ByteTracker.cpp` 的 `Impl` 类中，完成 `DetectionBox` 到 ByteTrack 内部格式的转换：

```cpp
// ByteTracker.cpp

#include "esdk_sophon/vision/tracker/ByteTracker.h"
#include "BYTETracker.h"  // third_party/bytetrack/include/

namespace esdk_sophon {
namespace vision {
namespace tracker {

class ByteTracker::Impl {
public:
    explicit Impl(const ByteTrackerConfig& config) {
        bytetrack_params params;
        params.track_thresh = config.trackThresh;
        params.match_thresh = config.matchThresh;
        params.frame_rate = config.frameRate;
        params.track_buffer = config.trackBuffer;
        params.min_box_area = config.minBoxArea;

        tracker_ = std::make_unique<BYTETracker>(params);
    }

    std::vector<TrackedObject> update(const std::vector<DetectionBox>& detections) {
        // 内部转换：DetectionBox → ByteTrack 内部格式
        std::vector<ByteTrackBox> btBoxes;
        btBoxes.reserve(detections.size());

        for (const auto& det : detections) {
            ByteTrackBox box;
            box.x = static_cast<float>(det.x);
            box.y = static_cast<float>(det.y);
            box.width = static_cast<float>(det.width);
            box.height = static_cast<float>(det.height);
            box.score = det.confidence;
            box.class_id = det.classId;
            btBoxes.push_back(box);
        }

        // 调用 ByteTrack 核心算法
        STracks outputTracks;
        tracker_->update(outputTracks, btBoxes);

        // 转换回项目格式：STrack → TrackedObject
        std::vector<TrackedObject> result;
        result.reserve(outputTracks.size());

        for (const auto& track : outputTracks) {
            TrackedObject obj;
            obj.trackId = track->track_id;
            obj.x = static_cast<int>(track->tlbr[0]);
            obj.y = static_cast<int>(track->tlbr[1]);
            obj.width = static_cast<int>(track->tlbr[2] - track->tlbr[0]);
            obj.height = static_cast<int>(track->tlbr[3] - track->tlbr[1]);
            obj.confidence = track->score;
            obj.classId = track->class_id;
            obj.isNew = (track->tracklet_len == 1);
            result.push_back(obj);
        }

        return result;
    }

private:
    std::unique_ptr<BYTETracker> tracker_;
};

}  // namespace tracker
}  // namespace vision
}  // namespace esdk_sophon
```

**设计说明**：

- **对外接口**：使用项目已有的 `DetectionBox` 类型，无需用户做任何转换
- **内部实现**：在 Pimpl 内部完成格式转换，对用户透明
- **扩展性**：如果将来换用其他追踪算法，只需修改 Impl 实现，对外接口不变---

### 3.2 SmartZoomCaptureStrategy 智能变焦拍照策略

#### 3.2.1 模块职责

- 根据追踪结果判断是否需要触发变焦拍照
- 管理拍照状态机（巡航 → 追踪 → 拍照 → 冷却）
- 计算最佳拍照区域（目标群体中心）
- 防止重复拍照（基于距离和时间的冷却机制）

#### 3.2.2 文件结构

按照项目规范，公共头文件放在 `include/esdk_sophon/`：

```
# 公共头文件
include/esdk_sophon/vision/strategy/
├── IZoomCaptureStrategy.h         # 策略接口
└── SmartZoomCaptureStrategy.h     # 智能策略头文件

# 源文件实现
src/vision/strategy/
└── SmartZoomCaptureStrategy.cpp   # 智能策略实现
```

#### 3.2.3 状态机设计

```
┌─────────────────────────────────────────────────────────────────┐
│                     状态转换图                                   │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│    ┌──────────┐   目标数 >= N 且稳定 M 帧    ┌──────────┐       │
│    │ CRUISING │ ─────────────────────────→ │ TRACKING │       │
│    │  巡航中   │                             │  追踪中   │       │
│    └──────────┘                             └────┬─────┘       │
│         ↑                                        │             │
│         │                                        │ 确认触发    │
│         │ 冷却完成                               ↓             │
│    ┌──────────┐                             ┌──────────┐       │
│    │ COOLDOWN │ ←─────────────────────────  │ CAPTURING│       │
│    │  冷却中   │        拍照完成             │  拍照中   │       │
│    └──────────┘                             └──────────┘       │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

状态说明：
- CRUISING:  正常检测，等待目标出现
- TRACKING:  检测到目标群体，等待稳定确认
- CAPTURING: 正在执行变焦拍照流程
- COOLDOWN:  拍照后冷却，防止重复拍照
```

```cpp
/**
 * @file SmartZoomCaptureStrategy.h
 * @brief 智能变焦拍照策略
 */

#ifndef ESDK_SOPHON_VISION_STRATEGY_SMARTZOOMCAPTURESTRATEGY_H_
#define ESDK_SOPHON_VISION_STRATEGY_SMARTZOOMCAPTURESTRATEGY_H_

#include "IZoomCaptureStrategy.h"
#include <chrono>
#include <deque>

namespace esdk_sophon {
namespace vision {
namespace strategy {

/**
 * @brief 智能变焦拍照配置
 */
struct SmartZoomCaptureConfig {
    // 触发条件
    int minTargetCount = 3;           ///< 最小目标数量
    int stableFrameCount = 5;         ///< 连续稳定帧数

    // 冷却机制
    double cooldownSeconds = 30.0;    ///< 时间冷却（秒）
    double cooldownDistanceMeters = 50.0;  ///< 距离冷却（米）

    // 目标过滤
    float minConfidence = 0.5f;       ///< 最小置信度
    int minBoxArea = 100;             ///< 最小目标面积
};

/**
 * @brief 策略状态枚举
 */
enum class CaptureState {
    CRUISING,   ///< 巡航中，等待目标
    TRACKING,   ///< 追踪中，等待稳定
    CAPTURING,  ///< 拍照中
    COOLDOWN    ///< 冷却中
};

/**
 * @brief 智能变焦拍照策略
 *
 * 实现基于目标密度的智能拍照触发：
 * 1. 检测到 N 个以上目标
 * 2. 连续 M 帧保持稳定
 * 3. 距离上次拍照位置超过 D 米或时间超过 T 秒
 */
class SmartZoomCaptureStrategy : public IZoomCaptureStrategy {
public:
    explicit SmartZoomCaptureStrategy(const SmartZoomCaptureConfig& config);
    ~SmartZoomCaptureStrategy() override;

    bool process(
        const std::vector<tracker::TrackedObject>& trackedObjects,
        const cv::Size& frameSize,
        const std::tuple<double, double, double>& gpsInfo) override;

    ZoomCaptureRequest getCaptureRequest() const override;
    void onCaptureComplete(bool success) override;
    void reset() override;

    // 状态查询
    CaptureState getState() const { return state_; }
    int getStableCount() const { return stableCount_; }

private:
    /**
     * @brief 检查是否满足触发条件
     */
    bool checkTriggerCondition(
        const std::vector<tracker::TrackedObject>& trackedObjects);

    /**
     * @brief 检查冷却状态
     */
    bool checkCooldown(const std::tuple<double, double, double>& gpsInfo);

    /**
     * @brief 计算目标群体包围框
     */
    cv::Rect calculateBoundingRegion(
        const std::vector<tracker::TrackedObject>& trackedObjects);

    /**
     * @brief 计算两个 GPS 坐标之间的距离（米）
     */
    double calculateGpsDistance(
        double lat1, double lon1, double lat2, double lon2);

private:
    SmartZoomCaptureConfig config_;
    CaptureState state_ = CaptureState::CRUISING;

    // 稳定检测
    int stableCount_ = 0;
    std::deque<int> recentTargetCounts_;

    // 冷却管理
    std::chrono::steady_clock::time_point lastCaptureTime_;
    double lastCaptureLat_ = 0.0;
    double lastCaptureLon_ = 0.0;
    bool hasLastCapture_ = false;

    // 当前请求
    ZoomCaptureRequest currentRequest_;
};

}  // namespace strategy
}  // namespace vision
}  // namespace esdk_sophon

#endif  // ESDK_SOPHON_VISION_STRATEGY_SMARTZOOMCAPTURESTRATEGY_H_
```

#### 3.3.2 主检测流程修改

```cpp
void LiveStreamTask::processFrame(const cv::Mat& frame, const FrameMetadata& metadata) {
    // 1. 目标检测 (已有)
    auto detections = detector_->detect(frame);

    // 2. 目标追踪 (新增)

    if (tracker_) {

    }

    // 3. 更新计数到 EventCache (新增)
    if (tracker_) {
        eventCache_.updateTargetCount(tracker_->getUniqueCount());
    }

    // 4. 变焦拍照决策 (新增)
    if (enableZoomCapture_ && zoomCaptureStrategy_) {
        auto gpsInfo = std::make_tuple(
            metadata.latitude, metadata.longitude, metadata.altitude);

        if (zoomCaptureStrategy_->process(trackedObjects, frame.size(), gpsInfo)) {
            // 触发拍照
            auto request = zoomCaptureStrategy_->getCaptureRequest();
            {
                std::lock_guard<std::mutex> lock(zoomCaptureMutex_);
                captureRequests_.push(request);
            }
            zoomCaptureCv_.notify_one();
        }
    }

    // 5. 绘制检测结果、推流等 (已有)
    // ...
}
```

#### 3.3.3 变焦拍照线程

```cpp
void LiveStreamTask::zoomCaptureThreadLoop() {
    LOG_INFO("变焦拍照线程启动");

    while (zoomCaptureRunning_) {
        vision::strategy::ZoomCaptureRequest request;

        // 等待拍照请求
        {
            std::unique_lock<std::mutex> lock(zoomCaptureMutex_);
            zoomCaptureCv_.wait(lock, [this] {
                return !captureRequests_.empty() || !zoomCaptureRunning_;
            });

            if (!zoomCaptureRunning_) break;

            request = captureRequests_.front();
            captureRequests_.pop();
        }

        // 执行变焦拍照流程
        bool success = executeZoomCapture(request);

        // 通知策略拍照完成
        if (zoomCaptureStrategy_) {
            zoomCaptureStrategy_->onCaptureComplete(success);
        }
    }

    LOG_INFO("变焦拍照线程退出");
}

bool LiveStreamTask::executeZoomCapture(
    const vision::strategy::ZoomCaptureRequest& request)
{
    LOG_INFO("开始执行变焦拍照流程，目标数量: {}", request.targetCount);

    try {
        // Step 1: 暂停航线
        LOG_DEBUG("Step 1: 暂停航线任务");
        if (!mqttClient_->pauseWayline()) {
            LOG_ERROR("暂停航线失败");
            return false;
        }
        std::this_thread::sleep_for(std::chrono::milliseconds(500));

        // Step 2: 框选变焦
        LOG_DEBUG("Step 2: 执行框选变焦");
        if (!mqttClient_->frameZoom(
                cameraPayloadIndex_,
                request.targetRegion.x,
                request.targetRegion.y,
                request.targetRegion.x + request.targetRegion.width,
                request.targetRegion.y + request.targetRegion.height)) {
            LOG_WARN("框选变焦失败，尝试设置固定倍率");
            mqttClient_->setFocalLength(cameraPayloadIndex_, 5.0);  // 5倍变焦
        }
        std::this_thread::sleep_for(std::chrono::milliseconds(1000));

        // Step 3: 拍照
        LOG_DEBUG("Step 3: 执行拍照");
        if (!mqttClient_->takePhoto(cameraPayloadIndex_)) {
            LOG_ERROR("拍照失败");
            // 继续执行，不中断流程
        }
        std::this_thread::sleep_for(std::chrono::milliseconds(500));

        // Step 4: 云台复位
        LOG_DEBUG("Step 4: 云台复位");
        mqttClient_->resetGimbal(cameraPayloadIndex_);
        std::this_thread::sleep_for(std::chrono::milliseconds(500));

        // Step 5: 恢复航线
        LOG_DEBUG("Step 5: 恢复航线任务");
        if (!mqttClient_->resumeWayline()) {
            LOG_ERROR("恢复航线失败");
            return false;
        }

        LOG_INFO("变焦拍照流程完成");
        return true;

    } catch (const std::exception& e) {
        LOG_ERROR("变焦拍照异常: {}", e.what());
        // 异常时尝试恢复航线
        mqttClient_->resumeWayline();
        return false;
    }
}
```

## 6. 风险与缓解

| 风险              | 影响             | 缓解措施                        |
