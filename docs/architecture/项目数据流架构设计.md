## 🔍 Edge-SDK 架构分析

### 核心发现 ⭐

**Edge-SDK 的设计模式**:

- `ImageProcessor::Process(std::shared_ptr<cv::Mat> image)` 是**统一处理接口**
- 无论数据来自**实时 H264 流**还是**离线 JPEG 文件**,最终都转换为`cv::Mat`
- `StreamDecoder`负责 H264→cv::Mat 转换
- `ImageProcessor`只关心 cv::Mat,**不关心数据来源**!

### Edge-SDK 数据流

```
实时视频流:
Liveview ─H264→ StreamDecoder ─cv::Mat→ ImageProcessor::Process()

离线图片:
MediaManager ─JPEG→ cv::imdecode ─cv::Mat→ ImageProcessor::Process()
```

**统一的处理接口**:

```cpp
// Edge-SDK提供的接口
class ImageProcessor {
public:
    using Image = cv::Mat;
    virtual void Process(const std::shared_ptr<Image> image) = 0;
};

// 用户实现(如YOLO检测)
class ImageProcessorYolovFastest : public ImageProcessor {
    void Process(const std::shared_ptr<Image> image) override {
        // 检测逻辑,不关心数据来自哪里!
        cv::Mat& frame = *image;
        detect(frame);
        post_process(frame);
    }
};
```

## 🔧 核心技术点

### 1. 统一的数据接口

**关键设计**: 所有数据源最终都转换为`std::shared_ptr<cv::Mat>`

```cpp
// DeviceManager.h

class DeviceManager {
public:
    // 统一的图像回调类型
    using ImageCallback = std::function<void(std::shared_ptr<cv::Mat> image)>;

    // 数据源1: 实时视频流
    bool startLiveview(ImageCallback callback);

    // 数据源2: 媒体文件
    bool processMediaFile(const std::string& fileId, ImageCallback callback);
};
```

**为什么用`shared_ptr<cv::Mat>`?**

- ✅ 避免大图像拷贝 (一帧可能几 MB)
- ✅ 多线程安全共享
- ✅ 自动内存管理
- ✅ 与 Edge-SDK 接口一致

### 2. 复用 Edge-SDK 的 StreamDecoder

**不要重复造轮子!** Edge-SDK 已经提供了完善的 H264 解码器:

```cpp
// DeviceManager::Impl

#include "ffmpeg_stream_decoder.h"  // Edge-SDK提供

class DeviceManager::Impl {
    bool startLiveview(ImageCallback callback) {
        // 1. 创建FFmpeg解码器 (复用Edge-SDK)
        StreamDecoder::Options decoderOpt = {.name = "H264Decoder"};
        h264Decoder_ = edge_app::CreateStreamDecoder(decoderOpt);
        h264Decoder_->Init();

        // 2. 保存用户回调
        imageCallback_ = callback;

        // 3. 设置Liveview的H264回调
        auto h264Callback = [this](const uint8_t* buf, uint32_t len) -> ErrorCode {
            // H264数据到达,交给解码器
            h264Decoder_->Decode(buf, len,
                [this](std::shared_ptr<cv::Mat>& image) {
                    // 解码完成,调用用户回调
                    if (imageCallback_) {
                        imageCallback_(image);
                    }
                }
            );
            return kOk;
        };

        // 4. 启动Liveview
        Liveview::Options opt = {
            .camera = kCameraTypePayload,
            .quality = kStreamQuality720p,
            .callback = h264Callback
        };
        liveview_->Init(opt);
        liveview_->StartH264Stream();

        return true;
    }

private:
    std::shared_ptr<edge_app::StreamDecoder> h264Decoder_;  // 复用Edge-SDK
    ImageCallback imageCallback_;
};
```

### 3. JPEG 解码 (OpenCV)

```cpp
bool DeviceManager::Impl::processMediaFile(const std::string& fileId,
                                           ImageCallback callback) {
    // 1. 读取JPEG文件 (MediaManager)
    auto fd = mediaReader_->Open(fileId);
    std::vector<uint8_t> jpegData;
    // ...read data...
    mediaReader_->Close(fd);

    // 2. 解码为cv::Mat (OpenCV)
    cv::Mat image = cv::imdecode(jpegData, cv::IMREAD_COLOR);
    if (image.empty()) {
        logger_.error("JPEG解码失败");
        return false;
    }

    // 3. 封装为shared_ptr
    auto imagePtr = std::make_shared<cv::Mat>(image);

    // 4. 调用用户回调 (与视频流完全一致!)
    callback(imagePtr);

    return true;
}
```

### 4. VisionProcessor 统一接口

```cpp
// vision/VisionProcessor.h

class VisionProcessor {
public:
    struct DetectionResult {
        std::vector<BBox> bboxes;
        cv::Mat segmentationMask;
        double confidence;
        std::string toJSON() const;
    };

    // 统一处理接口 (模仿Edge-SDK的ImageProcessor)
    virtual DetectionResult process(std::shared_ptr<cv::Mat> image) = 0;
};

// YOLOv10检测器
class YOLOv10Detector : public VisionProcessor {
public:
    DetectionResult process(std::shared_ptr<cv::Mat> image) override {
        cv::Mat& frame = *image;  // 解引用shared_ptr

        // 1. 预处理
        cv::Mat blob = preprocess(frame);

        // 2. 推理
        auto output = model_->infer(blob);

        // 3. 后处理
        return postprocess(output, frame.size());
    }

private:
    std::shared_ptr<YOLOv10Model> model_;
};
```

## 📋 Main 程序流程

### 完整示例代码

```cpp
// src/main.cpp

int main() {
    // ========== 1. 初始化基础设施 ==========
    Logger::getInstance().initialize();
    Config::getInstance().load("config.json");

    // ========== 2. 初始化DeviceManager ==========
    DeviceManager& deviceMgr = DeviceManager::getInstance();
    if (!deviceMgr.initialize()) {
        LOG_FATAL("DeviceManager初始化失败");
        return -1;
    }
    if (!deviceMgr.connect()) {
        LOG_FATAL("连接DJI Dock失败");
        return -1;
    }

    // ========== 3. 初始化VisionProcessor ==========
    auto yoloDetector = std::make_shared<YOLOv10Detector>();
    yoloDetector->initialize("/path/to/yolov10.onnx");

    // ========== 4. 初始化MqttClient ==========
    MqttClient& mqttClient = MqttClient::getInstance();
    mqttClient.initialize();
    mqttClient.connect();

    // ========== 5. 定义统一的图像处理回调 ==========
    bool isLiveviewMode = false;  // 标记当前模式

    auto imageProcessCallback = [&](std::shared_ptr<cv::Mat> image) {
        LOG_INFO("收到图像: " + std::to_string(image->cols) + "x" +
                 std::to_string(image->rows));

        // 1. 调用Vision模块检测 (统一接口!)
        auto results = yoloDetector->process(image);

        // 2. 上报检测结果到MQTT
        json resultJson = {
            {"detections", results.toJSON()},
            {"timestamp", getCurrentTimestamp()},
            {"device_sn", "analysis_device_WRSE7001"}
        };
        mqttClient.publish("drone/{sn}/info/event", resultJson.dump());

        // 3. 如果是视频流模式,进行推流
        if (isLiveviewMode) {
            // 在图像上绘制检测框
            cv::Mat annotated = image->clone();
            for (auto& bbox : results.bboxes) {
                cv::rectangle(annotated, bbox.rect, cv::Scalar(0,255,0), 2);
                cv::putText(annotated, bbox.label, bbox.rect.tl(),
                           cv::FONT_HERSHEY_SIMPLEX, 0.5, cv::Scalar(0,255,0), 2);
            }

            // 推送到RTMP服务器
            RtmpStreamer::getInstance().push(annotated);
        }
    };

    // ========== 6. 注册MQTT命令处理器 ==========
    class CommandHandler : public IMqttMessageObserver {
        DeviceManager& deviceMgr_;
        ImageCallback imageCallback_;
        bool& isLiveviewMode_;

    public:
        CommandHandler(DeviceManager& mgr, ImageCallback cb, bool& mode)
            : deviceMgr_(mgr), imageCallback_(cb), isLiveviewMode_(mode) {}

        void onMessageReceived(const std::string& topic,
                              const std::string& message) override {
            auto cmd = json::parse(message);

            if (cmd["method"] == "device_algorithm_enable") {
                int source = cmd["source"];
                std::string algType = cmd["algorithm_type"];

                LOG_INFO("收到算法启用指令: source=" + std::to_string(source) +
                        ", type=" + algType);

                if (source == 0) {
                    // 实时视频流分析
                    isLiveviewMode_ = true;

                    // 启动RTMP推流
                    RtmpStreamer::getInstance().start("rtmp://server/live/stream");

                    // 启动视频流,使用统一回调
                    deviceMgr_.startLiveview(imageCallback_);

                    LOG_INFO("视频流分析已启动");

                } else if (source == 1) {
                    // 离线图片分析
                    isLiveviewMode_ = false;

                    // 获取媒体文件列表
                    auto files = deviceMgr_.listMediaFiles();
                    LOG_INFO("发现" + std::to_string(files.size()) + "个媒体文件");

                    // 逐个处理,使用统一回调
                    for (auto& file : files) {
                        LOG_INFO("处理文件: " + file.fileName);
                        deviceMgr_.processMediaFile(file.fileId, imageCallback_);
                    }

                    LOG_INFO("图片分析已完成");
                }

            } else if (cmd["method"] == "device_algorithm_disable") {
                // 停止算法
                if (isLiveviewMode_) {
                    deviceMgr_.stopLiveview();
                    RtmpStreamer::getInstance().stop();
                }
                LOG_INFO("算法已停止");
            }
        }

        // 其他IMqttMessageObserver接口实现...
        void onConnectionLost(const std::string& cause) override {
            LOG_ERROR("MQTT连接丢失: " + cause);
        }

        void onConnected(const std::string& serverUri) override {
            LOG_INFO("MQTT已连接: " + serverUri);
        }

        void onDeliveryComplete(int token) override {}
    };

    auto cmdHandler = std::make_shared<CommandHandler>(
        deviceMgr, imageProcessCallback, isLiveviewMode
    );

    mqttClient.addObserver(cmdHandler.get());
    mqttClient.subscribe("thing/product/{sn}/services");

    // ========== 7. 主循环 ==========
    LOG_INFO("系统启动完成,等待云端指令...");

    while (true) {
        std::this_thread::sleep_for(std::chrono::seconds(1));

        // 可选: 定期上报心跳
        // mqttClient.publish("...", heartbeat);
    }

    // ========== 8. 清理 ==========
    deviceMgr.disconnect();
    mqttClient.disconnect();

    return 0;
}
```

## 🎯 关键优势

### 1. 代码复用

**不重复造轮子**:

- ✅ 复用 Edge-SDK 的`StreamDecoder` (H264 解码)
- ✅ 复用 Edge-SDK 的`ImageProcessor`模式 (统一接口)
- ✅ 复用 OpenCV 的`cv::imdecode` (JPEG 解码)

### 2. 统一处理

**一套代码,两种数据源**:

```cpp
// imageProcessCallback 处理所有图像,不关心来源
auto imageProcessCallback = [&](std::shared_ptr<cv::Mat> image) {
    auto results = yoloDetector->process(image);  // 统一调用
    mqttClient.publish(results.toJSON());
};

// 视频流 → imageProcessCallback
deviceMgr.startLiveview(imageProcessCallback);

// 图片 → imageProcessCallback
deviceMgr.processMediaFile(fileId, imageProcessCallback);
```

### 3. 易于扩展

**添加新算法很简单**:

```cpp
class NewSegmentor : public VisionProcessor {
    DetectionResult process(std::shared_ptr<cv::Mat> image) override {
        // 新算法实现
    }
};

// 替换算法,Main程序不需要改动!
auto newSegmentor = std::make_shared<NewSegmentor>();
```

### 4. 符合 Edge-SDK 设计理念

**与 DJI 官方 SDK 保持一致**:

- Edge-SDK: `ImageProcessor::Process(shared_ptr<cv::Mat>)`
- 我们: `VisionProcessor::process(shared_ptr<cv::Mat>)`

## 📊 架构对比

### v1.0 设计(错误)

```
DeviceManager提供两个不同的接口:
- startLiveview(LiveviewCallback)  ← 回调cv::Mat
- downloadMediaFile(MediaFileCallback)  ← 回调cv::Mat

Vision模块需要两套处理逻辑:
- processLiveviewFrame(cv::Mat)
- processMediaFile(cv::Mat)
```

❌ **问题**: 重复代码,维护困难

### v2.0 设计(正确)

```
DeviceManager提供统一接口:
- startLiveview(ImageCallback)  ← 统一回调
- processMediaFile(ImageCallback)  ← 统一回调

Vision模块只需一套逻辑:
- VisionProcessor::process(shared_ptr<cv::Mat>)
```

✅ **优势**: 代码复用,符合 DRY 原则,与 Edge-SDK 一致
