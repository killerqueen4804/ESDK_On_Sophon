## 🎓 学到的知识点

### 1. 代码重构原则

✅ **一开始就弄清楚**:

- 命名要准确反映实际情况
- 不要因为怕麻烦而妥协
- 语义清晰比减少改动更重要

✅ **系统性修改**:

- 头文件、实现文件、工厂类、测试文件同步修改
- 用脚本批量处理重复操作
- 修改前先备份

### 2. PP-YOLOE vs YOLOv10

| 特性     | PP-YOLOE               | YOLOv10                |
| -------- | ---------------------- | ---------------------- |
| 来源     | PaddleDetection (百度) | Ultralytics            |
| Anchor   | Anchor-free            | Anchor-free            |
| NMS      | 需要                   | 不需要 (End-to-End)    |
| Backbone | CSPRepResNet           | CSPNet                 |
| 核心创新 | TAL + DFL              | CIB + Dual Assignments |

### 3. FastDeploy API

```cpp
// PP-YOLOE
#include <fastdeploy/vision/detection/ppdet/ppyoloe.h>
auto model = fastdeploy::vision::detection::PPYOLOE(
    model_file, params_file, option, ModelFormat::SOPHGO
);

// YOLOv10
#include <fastdeploy/vision/detection/contrib/yolov10.h>
auto model = fastdeploy::vision::detection::YOLOv10(
    model_file, params_file, option, ModelFormat::SOPHGO
);
```
