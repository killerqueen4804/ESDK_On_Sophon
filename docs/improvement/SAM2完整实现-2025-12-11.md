## 📖 关键知识点 (八股文)

### 1. Pimpl 惯用法

**Q: 什么是 Pimpl 惯用法？有什么好处？**

A: Pimpl (Pointer to Implementation) 是一种 C++ 设计模式：

- **定义**：将类的实现细节放在单独的 Impl 类中，通过指针访问
- **优点**：
  1. 编译隔离：修改实现不需要重新编译使用者
  2. ABI 稳定：接口不变，实现可以自由修改
  3. 隐藏依赖：头文件不需要包含实现细节
- **实现**：

  ```cpp
  // Sam2Segmentor.h (接口)
  class Sam2Segmentor {
  private:
      class Impl;
      std::unique_ptr<Impl> impl_;
  };

  // Sam2Segmentor.cpp (实现)
  class Sam2Segmentor::Impl {
      bm_handle_t bmHandle;
      // ... 实现细节
  };
  ```

### 2. RAII 原则

**Q: 什么是 RAII？如何应用到资源管理？**

A: RAII (Resource Acquisition Is Initialization) 资源获取即初始化：

- **核心思想**：利用对象生命周期管理资源
- **典型应用**：
  - 智能指针：`std::unique_ptr`, `std::shared_ptr`
  - 互斥锁：`std::lock_guard`, `std::unique_lock`
  - 文件流：`std::fstream` (自动关闭文件)
  - **本项目**：`Sam2Segmentor::Impl` 的析构函数自动释放 BMRuntime 资源

```cpp
~Impl() {
    if (encoderNet) {
        bmrt_destroy(encoderNet);  // 自动释放
    }
    if (bmHandle) {
        bm_dev_free(bmHandle);
    }
}
```

### 3. 策略模式

**Q: 为什么用 ISegmentor 接口？**

A: 策略模式 (Strategy Pattern)：

- **目的**：定义一系列算法，使它们可以互相替换
- **优点**：
  1. 符合开闭原则：对扩展开放，对修改封闭
  2. 避免大量 if-else
  3. 易于切换算法
- **本项目**：
  ```cpp
  ISegmentor (接口)
  ├── Sam2Segmentor (SAM2 实现)
  └── PaddleSegmentor (PaddleSeg 实现)
  ```

### 4. BMRuntime 推理流程

**Q: 描述 BMRuntime 的完整推理流程**

A:

1. **初始化设备**: `bm_dev_request(&bmHandle, deviceId)`
2. **创建上下文**: `bmrt_create(bmHandle)`
3. **加载模型**: `bmrt_load_bmodel(net, modelPath)`
4. **获取网络信息**: `bmrt_get_network_info(...)`
5. **分配输入内存**: `bm_malloc_device_byte(...)`
6. **拷贝输入数据**: `bm_memcpy_s2d(handle, devMem, hostData)`
7. **执行推理**: `bmrt_launch_tensor_ex(...)`
8. **同步等待**: `bm_thread_sync(handle)`
9. **拷贝输出数据**: `bm_memcpy_d2s(handle, hostData, devMem)`
10. **释放资源**: `bm_free_device(...)`, `bmrt_destroy(...)`

## 🎓 面试高频问题

### Q1: SAM2 为什么要分 Encoder 和 Decoder？

**A**:

1. **架构设计**：Encoder 提取图像特征（计算密集），Decoder 基于提示生成掩码（轻量级）
2. **性能优化**：一张图像只需运行一次 Encoder，可以对多个目标复用特征
3. **灵活性**：Encoder 输出可以缓存，支持交互式分割

### Q2: 如何优化 SAM2 的推理性能？

**A**:

1. **模型量化**：使用 F16 代替 F32，减少内存和计算量
2. **批处理**：将多个 Box 的 Decoder 输入打包成 Batch
3. **异步推理**：使用多线程并行处理
4. **内存池**：预分配 Tensor 内存，避免频繁分配释放
5. **ROI 裁剪**：只对检测框区域运行 Encoder

### Q3: 为什么选择 Box 中心点而不是 Box 四角？

**A**:

1. **简单有效**：SAM2 论文证明单点提示在大多数情况下已经足够
2. **稳定性**：中心点对 Box 位置偏差更鲁棒
3. **性能**：减少 Decoder 输入大小，加快推理
4. **扩展性**：可以根据需要添加更多点（如 Top-Left + Bottom-Right）
