## 🎯 修改内容

在 `config/config.json` 中添加了 SAM2 分割器的配置项。

---

## 📝 配置详情

### 添加位置

`config.json` → `segmentation` → `sam2`

### 配置结构

```json
{
  "segmentation": {
    "paddleseg": { ... },
    "sam2": {
      "enabled": true,
      "encoder_model_path": "/data/Edge-SDK/models/sam2/sam2_encoder_f16_1b.bmodel",
      "decoder_model_path": "/data/Edge-SDK/models/sam2/sam2_decoder_f16_1b.bmodel",
      "input_size": 1024,
      "use_box_prompt": true,
      "iou_threshold": 0.5
    }
  }
}
```

---

## 📊 配置字段说明

| 字段                 | 类型     | 默认值 | 说明                            |
| -------------------- | -------- | ------ | ------------------------------- |
| `enabled`            | `bool`   | `true` | 是否启用 SAM2 分割器            |
| `encoder_model_path` | `string` | -      | Encoder BModel 文件路径 (必需)  |
| `decoder_model_path` | `string` | -      | Decoder BModel 文件路径 (必需)  |
| `input_size`         | `int`    | `1024` | 模型输入尺寸 (固定 1024x1024)   |
| `use_box_prompt`     | `bool`   | `true` | 是否使用检测框中心点作为 Prompt |
| `iou_threshold`      | `float`  | `0.5`  | IOU 阈值，用于选择最佳掩码      |

## 💻 使用示例

### 1. 在代码中读取配置

```cpp
#include "esdk_sophon/core/Config.h"
#include "esdk_sophon/vision/segmentation/Sam2Segmentor.h"

// 加载配置文件
auto& config = esdk_sophon::core::Config::getInstance();
config.load("config/config.json");

// 检查是否启用
bool sam2Enabled = config.get<bool>("segmentation.sam2.enabled", false);
if (!sam2Enabled) {
    LOG_INFO("SAM2 分割器已禁用");
    return;
}

// 读取模型路径
std::string encoderPath = config.get<std::string>("segmentation.sam2.encoder_model_path");
std::string decoderPath = config.get<std::string>("segmentation.sam2.decoder_model_path");

// 读取其他参数 (可选)
int inputSize = config.get<int>("segmentation.sam2.input_size", 1024);
float iouThreshold = config.get<float>("segmentation.sam2.iou_threshold", 0.5f);

// 初始化分割器
auto segmentor = std::make_unique<esdk_sophon::vision::Sam2Segmentor>();
if (!segmentor->init(encoderPath, decoderPath)) {
    LOG_ERROR("SAM2 初始化失败");
    return;
}

LOG_INFO("SAM2 初始化成功");
```

### 2. 在 TaskService 中集成

```cpp
// TaskService.cpp

void TaskService::initSegmentor() {
    auto& config = core::Config::getInstance();

    // 检查是否启用 SAM2
    bool sam2Enabled = config.get<bool>("segmentation.sam2.enabled", false);
    if (!sam2Enabled) {
        logger_.info("SAM2 分割器未启用");
        return;
    }

    // 初始化 SAM2
    sam2Segmentor_ = std::make_unique<vision::Sam2Segmentor>();

    std::string encoderPath = config.get<std::string>("segmentation.sam2.encoder_model_path");
    std::string decoderPath = config.get<std::string>("segmentation.sam2.decoder_model_path");

    if (sam2Segmentor_->init(encoderPath, decoderPath)) {
        logger_.info("SAM2 分割器初始化成功");
        useSam2_ = true;
    } else {
        logger_.error("SAM2 分割器初始化失败");
        sam2Segmentor_.reset();
        useSam2_ = false;
    }
}

void TaskService::processFrame(const cv::Mat& frame) {
    // 1. 目标检测
    auto detResult = detector_->detect(frame);

    // 2. 如果启用 SAM2，进行精细分割
    if (useSam2_ && sam2Segmentor_ && !detResult.boxes.empty()) {
        auto segResults = sam2Segmentor_->segmentWithPrompts(frame, detResult.boxes);

        // 处理分割结果 (例如填充到事件中)
        for (size_t i = 0; i < segResults.size(); ++i) {
            const auto& seg = segResults[i];

            // 将轮廓点转换为多边形
            std::vector<Point> polygon;
            for (const auto& pt : seg.contours) {
                polygon.push_back({pt.x, pt.y});
            }

            // 添加到事件数据
            event.targets[i].polygons.push_back(polygon);
        }
    }
}
```

## ⚠️ 注意事项

### 1. 路径配置

- **绝对路径**: 必须使用设备上的绝对路径
- **权限问题**: 确保程序有读取模型文件的权限
- **文件存在**: 程序启动前确认模型文件已上传

### 2. 内存占用

SAM2 模型较大,注意:

- Encoder: ~150MB
- Decoder: ~50MB
- 运行时内存: ~500MB (取决于图像尺寸)

### 3. 性能优化

- **批处理**: Encoder 只运行一次,Decoder 对每个检测框运行
- **阈值设置**: 适当提高 `iou_threshold` 可以过滤低质量掩码
- **分辨率**: 输入图像过大时考虑先缩放
