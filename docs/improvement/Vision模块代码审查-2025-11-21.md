## 🚨 **发现的问题**

### ❌ **严重问题 1: 数据结构不一致**

#### 问题描述

Vision 模块定义了**两套不同的检测结果结构体**，导致概念混淆：

**1. `vision::DetectionResult` (IDetector.h)**

```cpp
// src/vision/detector/IDetector.h
struct DetectionBox {
    int classId;              // ✅ 有 classId
    std::string className;
    float confidence;
    int x, y, width, height;
};

struct DetectionResult {
    std::vector<DetectionBox> boxes;
    double preprocessTime;    // ✅ 有性能统计
    double inferenceTime;
    double postprocessTime;
};
```

**2. `types::DetectionResult` (DetectionResult.h)**

```cpp
// include/esdk_sophon/types/DetectionResult.h
struct Detection {
    std::string className;    // ❌ 没有 classId
    float confidence;
    int x, y, width, height;
};

struct DetectionResult {
    int taskID;               // ❌ 有任务信息
    int eventType;
    std::string timestamp;
    std::vector<Detection> detections;
    // ❌ 没有性能统计
};
```

#### 影响范围

1. **MediaFileTask.cpp** 使用 `types::DetectionResult`
2. **TaskService.cpp** 使用 `vision::DetectionResult`
3. **两者需要手动转换**，容易出错

#### 当前的转换代码（TaskService.cpp:243-263）

```cpp
// 2. 执行检测
vision::DetectionResult result = impl_->detector->detect(frame);

// 3. 转换结果格式 ❌ 手动转换，代码冗余
for (const auto& detBox : result.boxes) {

    box.classId = detBox.classId;      // ✅ vision 有 classId

    box.lon = 0.0;  // GPS 后续填充
```

### ⚠️ **问题 3: 职责混淆**

#### `types::DetectionResult` 的问题

```cpp
struct DetectionResult {
    int taskID;               // ❌ 任务信息不应该在这里
    int eventType;            // ❌ 事件类型不应该在这里
    std::string timestamp;    // ❌ 时间戳不应该在这里
    std::vector<Detection> detections;
    std::string imageUrl;     // ❌ URL 不应该在这里
    std::string videoUrl;     // ❌ URL 不应该在这里
};
```

**问题分析**：

- `types::DetectionResult` 混合了**检测结果**和**任务元数据**
- 违反了**单一职责原则**（SRP）
- 检测结果应该只包含**纯粹的检测数据**，不应该包含任务 ID、事件类型等业务信息

**正确的设计应该是**：

```cpp
// ✅ 纯粹的检测结果
struct DetectionResult {
    std::vector<Detection> detections;
    double preprocessTime;
    double inferenceTime;
    double postprocessTime;
};

// ✅ 业务事件（由 TaskService 构建）
struct DetectionEvent {
    std::string uuid;
    int taskID;
    int eventType;
    std::string timestamp;
    DetectionResult detection;  // 包含检测结果
    std::string imageBase64;
    // ...
};
```

### ⚠️ **问题 5: PPYoloeDetector 实现细节问题**

#### 5.1 硬编码的填充颜色

```cpp
// PPYoloeDetector.cpp:preprocess()
cv::Mat letterboxed = cv::Mat(inputHeight_, inputWidth_, CV_8UC3,
```

**问题**：

- 填充颜色 `(114, 114, 114)` 硬编码
- 应该作为配置参数，不同数据集可能需要不同的填充值

#### 5.2 缺少输入验证

```cpp
DetectionResult PPYoloeDetector::detect(const cv::Mat& image) {
    DetectionResult result;

    if (!initialized_) {
        logger_.error("检测器未初始化");
        return result;  // ✅ 有初始化检查
    }

    if (image.empty()) {
        logger_.error("输入图像为空");
        return result;  // ✅ 有空图检查
    }

    // ❌ 缺少通道数检查
    // ❌ 缺少图像格式检查（是否 BGR）
    // ❌ 缺少图像尺寸合理性检查（太小或太大）
```

**建议添加**：

```cpp
// ✅ 完善的输入验证
if (image.channels() != 3) {
    logger_.error("输入图像必须是3通道（BGR格式）");
    return result;
}

if (image.rows < 32 || image.cols < 32) {
    logger_.error("输入图像尺寸过小");
    return result;
}

if (image.rows > 4096 || image.cols > 4096) {
    logger_.warning("输入图像尺寸过大，可能影响性能");
}
```

#### 5.3 后处理中的边界检查不完整

```cpp
// PPYoloeDetector.cpp:postprocess()
// 边界检查
detBox.x = std::max(0, std::min(detBox.x, originalSize.width - 1));
detBox.y = std::max(0, std::min(detBox.y, originalSize.height - 1));
detBox.width = std::min(detBox.width, originalSize.width - detBox.x);
detBox.height = std::min(detBox.height, originalSize.height - detBox.y);
```

**问题**：

- 只修正了坐标，但没有验证修正后的框是否合理
- 如果修正后 `width` 或 `height` 变为 0，应该过滤掉这个检测框

**建议**：

```cpp
// ✅ 完善的边界检查
detBox.x = std::max(0, std::min(detBox.x, originalSize.width - 1));
detBox.y = std::max(0, std::min(detBox.y, originalSize.height - 1));
detBox.width = std::min(detBox.width, originalSize.width - detBox.x);
detBox.height = std::min(detBox.height, originalSize.height - detBox.y);

// 过滤无效框
if (detBox.width <= 0 || detBox.height <= 0) {
    logger_.warning("检测框尺寸无效，跳过");
    continue;
}

// 过滤过小的框（可选）
const int MIN_BOX_SIZE = 10;
if (detBox.width < MIN_BOX_SIZE || detBox.height < MIN_BOX_SIZE) {
    logger_.debug("检测框过小，跳过");
    continue;
}
```

```cpp
// include/esdk_sophon/vision/IDetector.h

namespace esdk_sophon {
namespace vision {

/**
 * @brief 单个检测目标
 */
struct Detection {
    int classId;              ///< 类别ID
    std::string className;    ///< 类别名称
    float confidence;         ///< 置信度 [0.0, 1.0]

    // 边界框坐标（像素）
    int x;                    ///< 左上角 x
    int y;                    ///< 左上角 y
    int width;                ///< 宽度（不用 w，保持清晰）
    int height;               ///< 高度（不用 h，保持清晰）

    // GPS 坐标（由 TaskService 计算后填充）
    double latitude = 0.0;    ///< 纬度
    double longitude = 0.0;   ///< 经度

    Detection() : classId(-1), confidence(0.0f),
                  x(0), y(0), width(0), height(0) {}

    cv::Point2f getCenter() const {
        return cv::Point2f(x + width / 2.0f, y + height / 2.0f);
    }

    cv::Rect toRect() const {
        return cv::Rect(x, y, width, height);
    }
};

/**
 * @brief 检测结果（纯粹的检测数据）
 */
struct DetectionResult {
    std::vector<Detection> detections;  ///< 检测目标列表

    // 性能统计
    double preprocessTime = 0.0;        ///< 预处理耗时 (ms)
    double inferenceTime = 0.0;         ///< 推理耗时 (ms)
    double postprocessTime = 0.0;       ///< 后处理耗时 (ms)

    double getTotalTime() const {
        return preprocessTime + inferenceTime + postprocessTime;
    }

    size_t getDetectionCount() const {
        return detections.size();
    }

    bool hasDetections() const {
        return !detections.empty();
    }
};

}  // namespace vision
}  // namespace esdk_sophon
```
