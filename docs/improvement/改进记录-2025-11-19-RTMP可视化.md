# RTMP 可视化功能实现

## [2025-11-19] 实现 RTMP 推流可视化与模拟检测

### 问题描述

用户反馈 RTMP 推流画面虽然颜色正常了，但没有看到任何检测框，看起来像是原始画面。
经检查，原因如下：

1. `LiveStreamTask` 直接推送了解码后的原始 `frame`，未进行任何绘制。
2. `TaskService::detectObjects` 是一个空实现（Stub），返回空检测框列表。

### 解决方案

为了验证端到端流程并满足用户"看到处理结果"的需求，进行了以下修改：

1. **模拟检测结果**:

   - 修改 `src/task/TaskService.cpp`，在 `detectObjects` 中硬编码添加一个模拟的 "person" 检测框。
   - 这样即使没有接入真实的 Vision 模块，也能产生检测数据。

2. **实现可视化绘制**:
   - 修改 `src/task/LiveStreamTask.cpp`。
   - 在推流前，显式调用 `service_->detectObjects` 获取检测框。
   - 使用 OpenCV (`cv::rectangle`, `cv::putText`) 将检测框和标签绘制在 `visualizedFrame` 上。
   - 将绘制后的 `visualizedFrame` 推送给 `RtmpStreamer`。

### 代码变动

**文件**: `src/task/TaskService.cpp`

```cpp
// 添加模拟检测框
BoundingBox dummyBox;
dummyBox.x = 100; dummyBox.y = 100;
dummyBox.w = 200; dummyBox.h = 150;
dummyBox.className = "person";
boxes.push_back(dummyBox);
```

**文件**: `src/task/LiveStreamTask.cpp`

```cpp
// 绘制检测框
cv::Mat visualizedFrame = frame.clone();
for (const auto& box : boxes) {
    cv::rectangle(visualizedFrame, ..., cv::Scalar(0, 255, 0), 2);
    cv::putText(visualizedFrame, ...);
}
rtmpStreamer_->pushFrame(visualizedFrame); // 推送可视化帧
```

### 预期效果

1. RTMP 推流画面中将出现一个绿色的矩形框，标签为 "person 0.95"。
2. 证明检测流程（模拟）和可视化流程已打通。

### 后续优化

当前方案在 `LiveStreamTask` 中为了可视化再次调用了 `detectObjects`，导致每帧检测两次（一次用于业务上报，一次用于可视化）。
虽然目前是模拟检测开销可忽略，但接入真实模型后需要优化：

- 修改 `TaskService::processFrame` 接口，使其返回检测结果或可视化图像，避免重复计算。
