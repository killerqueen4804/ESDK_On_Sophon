# 改进记录 - 2025-11-19 - 视觉可视化工具重构

## 1. 背景

用户提出在直播流和媒体文件处理中重复编写绘制检测框的代码不仅冗余，而且难以保证视觉风格一致。建议将绘制逻辑封装为通用工具。

## 2. 改进内容

### 2.1 新增 Visualizer 模块

创建了 `src/vision/Visualizer.cpp` 和 `include/esdk_sophon/vision/Visualizer.h`。

**主要功能**:

- `drawDetections`: 静态方法，接收图像和检测框列表，在图像上绘制。
- `getClassColor`: 内部方法，根据 `classId` 自动生成固定的颜色（使用黄金分割比算法生成高区分度颜色）。

**视觉风格**:

- **检测框**: 2px 线宽。
- **标签**: 包含类别名和置信度（如 "person 0.95"）。
- **背景条**: 文字下方绘制实心背景条，确保在复杂背景下文字清晰可见。
- **颜色**: 每个类别拥有固定的专属颜色，不再全是绿色。

### 2.2 集成到 LiveStreamTask

修改 `src/task/LiveStreamTask.cpp`，移除了硬编码的 OpenCV 绘制代码，改为调用 `vision::Visualizer::drawDetections`。

### 2.3 构建系统更新

修改 `src/vision/CMakeLists.txt`，将 `Visualizer.cpp` 加入 `vision_common` 库。

## 3. 优势

1.  **代码复用**: 未来 `MediaFileTask` 或其他模块需要绘制检测结果时，只需一行代码。
2.  **一致性**: 所有模块生成的图片风格统一。
3.  **可维护性**: 修改颜色、字体或布局只需修改 `Visualizer` 一处。
4.  **用户体验**: 自动配色使得多类别检测结果更易区分。

## 4. 下一步

- 考虑将颜色配置参数化（从 config.json 读取）。
