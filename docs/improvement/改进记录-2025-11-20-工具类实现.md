```cpp
// EXIF 有理数转换
static double exifRationalToDouble(ExifEntry* entry) {
    ExifByteOrder order = exif_data_get_byte_order(entry->parent->parent);

    ExifRational deg = exif_get_rational(entry->data, order);
    double degrees = (double)deg.numerator / (double)deg.denominator;

    ExifRational min = exif_get_rational(entry->data + 8, order);
    double minutes = (double)min.numerator / (double)min.denominator;

    ExifRational sec = exif_get_rational(entry->data + 16, order);
    double seconds = (double)sec.numerator / (double)sec.denominator;

    return degrees + minutes / 60.0 + seconds / 3600.0;
}
```

    std::string tempInputFile = "/tmp/geo_request.json";
    std::string tempOutputFile = "/tmp/geo_response.json";

    // 写入请求数据
    std::ofstream ofs(tempInputFile);
    ofs << jsonData;

    // 执行 curl
    std::ostringstream cmd;
    cmd << "curl -s -X POST \"" << url << "\" "
        << "-H \"Content-Type: application/json\" "
        << "-d @" << tempInputFile << " -o " << tempOutputFile;

    system(cmd.str().c_str());

    // 读取响应
    std::ifstream ifs(tempOutputFile);
    std::ostringstream ss;
    ss << ifs.rdbuf();
    response = ss.str();

#### 2. 距离计算

```cpp
double calculateDistance(const GpsCoordinate& from, const GpsCoordinate& to) const;  // Haversine 公式
double calculateDistanceVincenty(const GpsCoordinate& from, const GpsCoordinate& to) const;  // Vincenty 公式（高精度）
double calculateBearing(const GpsCoordinate& from, const GpsCoordinate& to) const;  // 方位角
GpsCoordinate calculateDestination(const GpsCoordinate& from, double distance, double bearing) const;  // 终点坐标
```

**核心技术**:

- **Haversine 公式**: 球面距离计算（精度 ~0.5%）
  - 假设地球是完美球体
  - 计算快速，适合大多数场景
- **Vincenty 公式**: 椭球距离计算（精度 ~0.0001%）
  - 考虑 WGS84 椭球参数（长短半轴、扁率）
  - 迭代收敛算法（最多 100 次）
  - 适合高精度场景（如航空导航）

**关键代码（Haversine）**:

```cpp
double lat1 = from.latitude * DEG_TO_RAD;
double lon1 = from.longitude * DEG_TO_RAD;
double lat2 = to.latitude * DEG_TO_RAD;
double lon2 = to.longitude * DEG_TO_RAD;

double dlat = lat2 - lat1;
double dlon = lon2 - lon1;

double a = std::sin(dlat / 2.0) * std::sin(dlat / 2.0) +
           std::cos(lat1) * std::cos(lat2) *
           std::sin(dlon / 2.0) * std::sin(dlon / 2.0);

double c = 2.0 * std::atan2(std::sqrt(a), std::sqrt(1.0 - a));

return EARTH_RADIUS_M * c;  // 6371000 米
```

#### 3. 区域判断

```cpp
bool isPointInPolygon(const GpsCoordinate& point, const Polygon& polygon) const;  // 点在多边形内
bool isPointInCircle(const GpsCoordinate& point, const GpsCoordinate& center, double radiusM) const;  // 点在圆内
bool isPointInRectangle(const GpsCoordinate& point, const GpsCoordinate& sw, const GpsCoordinate& ne) const;  // 点在矩形内
```

**核心技术**:

- **射线法（Ray Casting Algorithm）**: 判断点在多边形内
  - 从点向右发射射线，统计与多边形边的交点数
  - 奇数 → 在内，偶数 → 在外
  - 时间复杂度: O(n)，n 为多边形顶点数

**关键代码（射线法）**:

```cpp
bool inside = false;
size_t j = polygon.vertices.size() - 1;

for (size_t i = 0; i < polygon.vertices.size(); j = i++) {
    double xi = polygon.vertices[i].longitude;
    double yi = polygon.vertices[i].latitude;
    double xj = polygon.vertices[j].longitude;
    double yj = polygon.vertices[j].latitude;

    bool intersect = ((yi > point.latitude) != (yj > point.latitude)) &&
                    (point.longitude < (xj - xi) * (point.latitude - yi) / (yj - yi) + xi);

    if (intersect) inside = !inside;
}

return inside;
```

#### 5. 轨迹分析

```cpp
double calculateTrajectoryLength(const std::vector<GpsCoordinate>& trajectory) const;  // 轨迹总长度
std::vector<GpsCoordinate> smoothTrajectory(const std::vector<GpsCoordinate>& trajectory, int windowSize = 5) const;  // 轨迹平滑
std::vector<GpsCoordinate> simplifyTrajectory(const std::vector<GpsCoordinate>& trajectory, double epsilon = 10.0) const;  // 轨迹简化
```

**核心技术**:

- **轨迹长度**: 逐段求和距离
- **移动平均平滑**: 滑动窗口平均（减少 GPS 漂移）
- **Douglas-Peucker 算法**: 轨迹简化（保留关键点）
  - 递归查找离直线最远的点
  - 如果距离 > ε，保留该点并递归两侧
  - 如果距离 ≤ ε，删除中间所有点

**关键代码（Douglas-Peucker）**:

```cpp
std::function<void(int, int, std::vector<bool>&)> douglasPeucker =
    [&](int start, int end, std::vector<bool>& keep) {
        if (end - start < 2) return;

        // 找到距离直线最远的点
        double maxDistance = 0.0;
        int maxIndex = start;

        for (int i = start + 1; i < end; ++i) {
            double d = perpendicularDistance(trajectory[i], trajectory[start], trajectory[end]);
            if (d > maxDistance) {
                maxDistance = d;
                maxIndex = i;
            }
        }

        // 如果距离 > epsilon，递归处理
        if (maxDistance > epsilon) {
            keep[maxIndex] = true;
            douglasPeucker(start, maxIndex, keep);
            douglasPeucker(maxIndex, end, keep);
        }
    };
```

#### 2. 重试机制

```cpp

void retryAll();           // 重试所有缓存事件
void retryById(const std::string& eventId);  // 重试单个事件
```

**重试逻辑**:

1. 清理过期事件（> 3600 秒）
2. 检查重试次数（最多 5 次）
3. 尝试发布
4. 成功 → 删除缓存
5. 失败 → 增加重试次数

**关键代码**:

```cpp
void EventCache::retryAll() {
    auto it = cachedEvents_.begin();
    while (it != cachedEvents_.end()) {
        // 检查过期
        if (it->isExpired(expirationSeconds_)) {
            it = cachedEvents_.erase(it);
            continue;
        }

        // 检查重试次数
        if (it->retryCount >= maxRetries_) {
            it = cachedEvents_.erase(it);
            continue;
        }

        // 尝试发布
        if (publishCallback_(it->topic, it->data)) {
            it = cachedEvents_.erase(it);  // 成功删除
        } else {
            it->retryCount++;
            ++it;
        }
    }
}
```

### 面试要点

#### Q: 如何判断点在多边形内？

A: 使用**射线法（Ray Casting Algorithm）**：

- 从点向右发射射线
- 统计与多边形边的交点数
- 奇数 → 在内，偶数 → 在外
- 时间复杂度 O(n)，n 为顶点数

#### Q: Haversine 和 Vincenty 公式有什么区别？

A:

- **Haversine**: 假设地球是完美球体，精度 ~0.5%，计算快
- **Vincenty**: 考虑 WGS84 椭球，精度 ~0.0001%，需要迭代收敛
- 场景选择：普通应用用 Haversine，高精度场景（航空）用 Vincenty

#### Q: 如何实现事件缓存与重试？

A:

1. **内存缓存**: `std::vector<CachedEvent>` 队列
2. **文件持久化**: JSON 格式保存到磁盘
3. **重试机制**: MQTT 重连时触发 `retryAll()`
4. **过期清理**: 超过 3600 秒自动删除
5. **重试次数限制**: 最多 5 次

#### Q: 如何实现 LRU 缓存？

A: 本项目使用简化版：

- `std::map<std::string, PixelCoordinate>` 存储
- 当大小 >= maxSize 时，删除第一个元素（`pixelCache_.begin()`）
- ⚠️ 简化版不是严格 LRU（应该使用 `std::list` + `std::unordered_map` 实现）
