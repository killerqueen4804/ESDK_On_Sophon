### 1. GPS 数据集成

#### 1.1 创建 FlightDataProvider 类

**文件**: `include/esdk_sophon/device/FlightDataProvider.h`

**设计说明**:

- 实现单例模式 (Meyers 单例)
- 使用 `std::shared_mutex` 读写锁实现高效并发访问
- 存储飞行器 GPS 位置、姿态、速度信息

**核心结构体**:

```cpp
struct GpsPosition {
    double latitude;   // 纬度 (-90 ~ 90)
    double longitude;  // 经度 (-180 ~ 180)
    double height;     // 椭球高度 (米)
    double altitude;   // 海拔高度 (米)

    // Haversine 公式计算距离
    double distanceTo(const GpsPosition& other) const;
    bool isValid() const;
};
```

**📌 面试考点**:

Q: 为什么使用 `std::shared_mutex` 而不是 `std::mutex`？

A: `shared_mutex` 允许多个读者同时访问，只有写者需要独占锁。在我们的场景中：

- OSD 数据更新频率：0.5Hz（写）
- 检测循环读取频率：10-30Hz（读）

这是典型的读多写少场景，使用 `shared_mutex` 可以避免读者之间互相阻塞，提高性能。

## 📚 相关八股知识点

### Haversine 公式

用于计算球面上两点之间的最短距离（大圆距离）：

```cpp
double GpsPosition::distanceTo(const GpsPosition& other) const {
    constexpr double R = 6371000.0;  // 地球半径 (米)

    double lat1 = latitude * M_PI / 180.0;
    double lat2 = other.latitude * M_PI / 180.0;
    double deltaLat = (other.latitude - latitude) * M_PI / 180.0;
    double deltaLon = (other.longitude - longitude) * M_PI / 180.0;

    double a = sin(deltaLat / 2) * sin(deltaLat / 2) +
               cos(lat1) * cos(lat2) *
               sin(deltaLon / 2) * sin(deltaLon / 2);
    double c = 2 * atan2(sqrt(a), sqrt(1 - a));

    return R * c;  // 返回距离 (米)
}
```

### 读写锁 (shared_mutex)

```cpp
class FlightDataProvider {
    mutable std::shared_mutex mutex_;
    GpsPosition gpsPosition_;

public:
    // 写操作：独占锁
    void updateGpsPosition(double lat, double lon, double h, double alt) {
        std::unique_lock<std::shared_mutex> lock(mutex_);
        gpsPosition_ = {lat, lon, h, alt};
    }

    // 读操作：共享锁
    GpsPosition getGpsPosition() const {
        std::shared_lock<std::shared_mutex> lock(mutex_);
        return gpsPosition_;  // 返回副本
    }
};
```
