## 💻 代码使用

### 基本用法

```cpp
#include "esdk_sophon/vision/VisionConfigLoader.h"
#include "esdk_sophon/core/Config.h"

// 1. 加载config.json
auto& config = core::Config::getInstance();
config.load("config/config.json");

// 2. 创建配置加载器
vision::VisionConfigLoader loader;

// 3. 加载检测器配置
auto detectorConfig = loader.loadDetectorConfig("ppyoloe");

// 4. 加载分割器配置
auto segmentorConfig = loader.loadSegmentorConfig("paddleseg");

// 5. 使用配置初始化模块
detector->initialize(detectorConfig);
segmentor->initialize(segmentorConfig);
```

### 检测器配置结构

```cpp
struct DetectorConfig {
    std::string modelPath;            // 模型文件路径
    std::string configFile;           // 配置文件路径
    std::vector<std::string> classes; // 类别列表
    float confidenceThreshold;        // 置信度阈值
    float nmsThreshold;               // NMS阈值
    int inputWidth;                   // 输入宽度
    int inputHeight;                  // 输入高度
};
```

### 分割器配置结构

```cpp
struct SegmentorConfig {
    std::string modelPath;     // 模型文件路径
    std::string configPath;    // 配置文件路径
    int numClasses;            // 类别数量
    int inputWidth;            // 输入宽度
    int inputHeight;           // 输入高度
    bool enabled;              // 是否启用
};
```

## 🎯 常见问题

### Q: 如何修改模型路径?

A: 编辑 `config/config.json`,无需重新编译:

```json
{
  "detector": {
    "ppyoloe": {
      "model_path": "/your/new/path/model.bmodel" // 修改这里
    }
  }
}
```

### Q: 如何添加新的检测器类型?

A: 在 config.json 中添加新配置:

```json
{
  "detector": {
    "yolov8": {
      // 新检测器类型
      "model_path": "/path/to/yolov8.bmodel",
      "config_path": "/path/to/yolov8.yaml"
    }
  }
}
```

代码中使用:

```cpp
auto config = loader.loadDetectorConfig("yolov8");  // 传入类型名
```

### Q: 配置文件找不到怎么办?

A: VisionConfigLoader 会:

1. 记录警告日志
2. 返回默认配置
3. 使用 COCO 80 类默认标签

### Q: 如何在代码中获取原始配置值?

A: 直接使用 Config 单例:

```cpp
auto& config = core::Config::getInstance();
std::string path = config.getString("detector.ppyoloe.model_path");
int width = config.getInt("detector.ppyoloe.input_size[0]");
```
