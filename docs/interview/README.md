## 📝 文档规范

每个知识点文档包含以下结构:

### 1. 文件头

```markdown
# 八股知识点 - [知识点名称]

**知识点**: [简短描述]
**难度**: ⭐⭐⭐ (中级)
**来源**: Day X 任务模块开发 (2025-XX-XX)
**标签**: `标签1` `标签2` `标签3`
```

### 2. 核心内容

- **📌 核心概念**: 简明扼要的定义
- **🎯 项目实战案例**: 本项目中的实际代码
- **📊 对比分析**: 不同方案的优缺点对比
- **🎓 面试要点**: 高频问题和标准答案
- **💡 实战技巧**: 编程技巧和注意事项
- **🔗 相关知识点**: 关联的其他知识点
- **📝 总结**: 核心要点和面试答题模板

### 3. 文件尾

```markdown
**最后更新**: 2025-XX-XX
**下次复习**: 建议 1 周后
```

## 📖 使用指南

### 面试准备

1. **按标签复习**: 根据岗位要求重点复习相关标签
2. **按难度复习**: 从中级开始,逐步提升到高级
3. **项目驱动**: 每个知识点都有项目实战案例,便于讲述项目经验

### 日常学习

1. **遇到新知识点**: 创建新的八股文档
2. **完善已有知识点**: 在已有文档中补充项目例子
3. **定期复习**: 每周复习标记为"下次复习"的文档

### 文档创建规范

```bash
# 文件命名
八股-[知识点名称].md

# 例如:
```

## 🎓 学习路径推荐

### 路径 1: C++ 核心特性

1. RAII 原则 → 智能指针 → 异常安全
2. 移动语义 → 右值引用 → 完美转发
3. 模板编程 → 类型推导 → SFINAE

### 路径 2: 设计模式

1. 静态工厂方法 → 工厂模式 → 抽象工厂
2. 单例模式 → 观察者模式 → 策略模式
3. RAII → 代理模式 → 装饰器模式

### 路径 3: 系统编程

1. 多线程基础 → 线程同步 → 无锁编程
2. 内存管理 → 内存池 → 垃圾回收
3. 网络编程 → 异步 IO → 事件驱动
