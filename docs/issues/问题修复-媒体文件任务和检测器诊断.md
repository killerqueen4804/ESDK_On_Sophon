## 🔍 问题分析

### 问题 1: `source: 1` 未触发 MediaFileTask

**根本原因**: `TaskConfig::fromJson()` 解析的是 `"dataSource"` 字段,但平台发送的是 `"source"` 字段

**你的 MQTT 消息**:

```json
{
  "source": 1, // ❌ 错误字段名
  "taskID": 4104
}
```

**代码期望**:

```json
{
  "dataSource": "file", // ✅ 正确字段名
  "taskID": 4104
}
```

**已修复**: ✅ 修改了 `TaskTypes.cpp`,现在同时支持 `source` 和 `dataSource` 两种格式

---

可能原因:

1. **检测器未初始化** (最可能)
2. **没有收到视频帧**
3. **eventTypes 配置不正确**

## 🔧 修复方案

### 修复 1: 兼容 `source` 字段 ✅

**文件**: `src/task/TaskTypes.cpp`

**修改前**:

```cpp
std::string dataSource = json.value("dataSource", "live");
if (dataSource == "live") {
    config.type = TaskType::DETECTION_LIVESTREAM;
}
```

**修改后**:

```cpp
// 支持两种格式：
// 1. "dataSource": "live" | "file" (字符串)
// 2. "source": 0 | 1 (数字, 0=live, 1=file)
std::string dataSource = "live";

if (json.contains("dataSource")) {
    dataSource = json["dataSource"].get<std::string>();
} else if (json.contains("source")) {
    int sourceValue = json["source"].get<int>();
    dataSource = (sourceValue == 1) ? "file" : "live";
}

if (dataSource == "live" || dataSource == "0") {
    config.type = TaskType::DETECTION_LIVESTREAM;
    config.source = DataSource::LIVESTREAM;
} else {
    config.type = TaskType::DETECTION_MEDIAFILE;
    config.source = DataSource::MEDIAFILE;
    config.mediaPath = json.value("baseFolder", "");
}
```

## 🐛 常见问题排查

### 问题: "检测器未初始化"

**原因**: TaskService 构造函数中检测器创建失败

**排查**:

```bash
# 1. 检查模型文件
ls -lh /data/Edge-SDK/models/PaddleDetection/

# 2. 检查配置文件路径
cat config/config.json | jq '.detector.ppyoloe'

# 3. 检查 TPU 状态
bm-smi

# 4. 查看详细错误日志
grep -A 10 "初始化检测器" /workspace/logs/*.log
```

**解决**:

- 确保模型文件存在
- 确认 TPU 可用
- 检查配置文件路径正确

---

### 问题: "未检测到目标"

**原因**:

1. 图像质量太差
2. 置信度阈值太高
3. eventTypes 类别过滤太严格

**排查**:

```bash
# 降低置信度阈值
"confidence": 0.1  # 从 0.25 降低到 0.1

# 查看原始检测结果数量
grep "原始检测" /workspace/logs/*.log
```

---

### 问题: LiveStreamTask 没有视频帧

**原因**: DJI SDK 未连接或 H.264 解码失败

**排查**:

```bash
# 检查 DJI 连接
grep "DJI" /workspace/logs/*.log

# 检查 H.264 解码
grep "decode" /workspace/logs/*.log

# 检查帧率
grep "FPS" /workspace/logs/*.log
```
