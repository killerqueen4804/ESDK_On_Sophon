# Logger 日志轮转功能测试指南

## 📋 功能说明

本 Logger 实现了完整的日志轮转功能：

### ✅ 已实现功能

1. **按日期自动切换**

   - 文件名格式：`logs/esdk_sophon_2025-10-25.log`
   - 每天 0 点或日期变化时自动切换
   - 跨天运行程序会自动创建新日期的日志文件

2. **自动清理旧日志**

   - 保留最近 15 天的日志
   - 程序启动时自动清理超过 15 天的日志文件
   - 清理过程会在控制台显示

3. **文件大小限制**

   - 单个日志文件最大 100MB
   - 超过后自动切换到序号文件：`esdk_sophon_2025-10-25_001.log`
   - 序号自动递增：\_001, \_002, \_003...

4. **线程安全**

   - 多线程环境下安全写入
   - 使用互斥锁保护临界区

5. **日志目录管理**
   - 自动创建 `logs/` 目录
   - 如果目录不存在，会自动创建


## 📚 知识点回顾

### C++17 std::filesystem

```cpp
fs::create_directories("logs");      // 创建多级目录
fs::exists("logs/xxx.log");          // 检查文件是否存在
fs::file_size("xxx.log");            // 获取文件大小
fs::last_write_time("xxx.log");      // 获取最后修改时间
fs::directory_iterator("logs");      // 遍历目录
fs::remove("old.log");               // 删除文件
```

### 日志轮转策略

1. **按时间轮转**：每天/每小时切换
2. **按大小轮转**：文件超过 N MB 切换
3. **保留策略**：只保留最近 N 天
4. **压缩策略**：旧日志压缩存储

### 面试要点

**Q: 如何管理日志文件，避免磁盘占满？**

A: 1. 按日期轮转（每天一个文件） 2. 文件大小限制（单文件最大 100MB） 3. 定期清理旧日志（保留 N 天） 4. 日志压缩（可选，节省空间） 5. 日志级别控制（生产环境关闭 DEBUG）

**Q: std::filesystem vs 传统 C API？**

A: - std::filesystem：C++17 标准，跨平台，面向对象

- C API (stat/opendir)：C 风格，平台相关，复杂
- 推荐使用 std::filesystem
