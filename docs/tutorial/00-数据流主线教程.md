# ESDK_On_Sophon 数据流主线教程

> 📅 创建日期：2025-11-27
> 🎯 **教程理念**：以数据流为主线，串联所有模块的知识点
> 📖 **阅读建议**：跟随数据的流动路径，逐步深入每个模块

---

## 为什么需要这个教程？

传统的模块化教程（Logger、Config、MQTT、Vision...）有一个问题：**各模块孤立讲解，难以形成整体认知**。

本教程采用不同的方式：**跟随一个真实请求的完整生命周期**，从云端消息到达，到检测结果返回，把所有模块串联起来。

```
传统教程：模块 A → 模块 B → 模块 C → ...（孤岛式学习）

本教程：跟随数据流动
         ┌──────┐     ┌──────┐     ┌──────┐     ┌──────┐
数据 ───▶│模块 A│───▶│模块 B│───▶│模块 C│───▶│模块 D│───▶ 结果
         └──────┘     └──────┘     └──────┘     └──────┘
         （每经过一个模块，学习该模块的知识点）
```

## 场景选择：媒体文件分析任务

我们选择**媒体文件分析任务**作为主线，原因：

1. 涵盖几乎所有模块（MQTT、Task、Vision、Device、Utils）
2. 流程完整（从消息接收到结果上报）
3. 包含多种设计模式（单例、工厂、观察者、策略、多态）

**场景描述**：

> 无人机执行航线任务，拍摄照片，返回机场后将照片下载到边缘计算盒子。
> 边缘盒子对每张照片进行 AI 目标检测，将检测结果上报云端平台。

```cpp
// 1. 收到消息（观察者回调）
void MqttHandler::onMessageReceived(const std::string& topic,
                                     const std::string& message) {
    // 2. 解析 JSON
    nlohmann::json json = nlohmann::json::parse(message);

    // 3. 路由到 handleServiceCommand
    handleServiceCommand(json);
}

// 4. 根据 method 字段分发
void MqttHandler::handleServiceCommand(const nlohmann::json& json) {
    std::string method = json.at("method").get<std::string>();
    nlohmann::json data = json.at("data");

    // 5. 查找路由表
    auto it = commandHandlers_.find(method);
    if (it != commandHandlers_.end()) {
        it->second(data);  // 调用对应处理函数
    }
}

// 6. 路由表初始化
void MqttHandler::initCommandHandlers() {
    commandHandlers_["device_algorithm_enable"] =
        [this](const nlohmann::json& data) { handleAlgorithmEnable(data); };

    commandHandlers_["device_algorithm_disable"] =
        [this](const nlohmann::json& data) { handleAlgorithmDisable(data); };

    commandHandlers_["device_task_end"] =
        [this](const nlohmann::json& data) { handleTaskEnd(data); };
}
```

### 📌 重点理解：指令路由表

```cpp
// 为什么用 map + function 而不是 switch-case？

// ❌ switch-case 的问题（违反开闭原则）
switch (method) {
    case "cmd1": handle1(); break;
    case "cmd2": handle2(); break;
    // 每次新增指令都要修改这里...
}

// ✅ map + function（符合开闭原则）
commandHandlers_["new_cmd"] = [](auto& data) { handleNew(data); };
// 只需添加一行，无需修改已有代码
```

```cpp
// MqttHandler 调用 TaskManager
void MqttHandler::handleAlgorithmEnable(const nlohmann::json& data) {
    // 1. 解析配置
    task::TaskConfig config = task::TaskConfig::fromJson(data);

    // 2. 启动任务（内部会创建任务）
    taskManager_.startTask(config);
}

// TaskManager 内部
bool TaskManager::startTask(const TaskConfig& config) {
    // 1. 创建任务（工厂模式）
    TaskPtr task = createTask(config);

    // 2. 启动任务
    return task->start();
}

TaskPtr TaskManager::createTask(const TaskConfig& config) {
    // ⭐ 工厂模式：根据类型创建不同的任务
    switch (config.type) {
        case TaskType::DETECTION_LIVESTREAM:
            return std::make_shared<LiveStreamTask>(config, taskService_);

        case TaskType::DETECTION_MEDIAFILE:  // source=1 时
            return std::make_shared<MediaFileTask>(config, taskService_);

        default:
            return nullptr;
    }
}
```

### MediaFileTask::start()

```cpp
bool MediaFileTask::start() {
    // 1. 配置 EventCache（事件缓存与重试）
    auto& cache = core::EventCache::getInstance();
    cache.setPublishCallback([this](const std::string& topic, const std::string& payload) {
        return service_->publishMqttMessage(topic, nlohmann::json::parse(payload));
    });

    // 2. ⭐ 注册 DJI MediaFilesObserver（关键！）
    registerMediaFilesObserver();

    // 3. 启动工作线程（消费者）
    workerThread_ = std::make_unique<std::thread>(&MediaFileTask::execute, this);

    // 4. 启动监控线程（超时检测）
    monitorThread_ = std::make_unique<std::thread>(&MediaFileTask::monitorLoop, this);

    state_ = TaskState::RUNNING;
    return true;
}
```

### 注册 MediaFilesObserver

```cpp
bool MediaFileTask::registerMediaFilesObserver() {
    // 1. 获取 MediaManager 实例
    mediaManager_ = edge_sdk::MediaManager::Instance();

    // 2. 注册观察者回调（Lambda 捕获 this）
    auto observer = [this](const edge_sdk::MediaFile& file) -> edge_sdk::ErrorCode {
        return this->onMediaFileUpdate(file);
    };

    edge_sdk::ErrorCode ret = mediaManager_->RegisterMediaFilesObserver(observer);

    // 3. 创建文件读取器
    mediaReader_ = mediaManager_->CreateMediaFilesReader();

    // 4. 配置：不自动删除文件（边缘计算需要）
    mediaManager_->SetDroneNestAutoDelete(false);

    return ret == edge_sdk::kOk;
}
```

### 文件入队（生产者）

```cpp
edge_sdk::ErrorCode MediaFileTask::onMediaFileUpdate(const edge_sdk::MediaFile& file) {
    // 1. 过滤视频文件（只处理图片）
    if (file.file_type == edge_sdk::MediaFile::kFileTypeMp4) {
        return edge_sdk::kOk;  // 跳过
    }

    // 2. 更新超时计时器
    {
        std::lock_guard<std::mutex> lock(timerMutex_);
        lastFileTime_ = std::chrono::steady_clock::now();
    }

    // 3. 文件入队（生产者）
    {
        std::lock_guard<std::mutex> lock(queueMutex_);
        fileQueue_.push(file);
    }

    // 4. 通知消费者线程
    queueCv_.notify_one();

    return edge_sdk::kOk;
}
```

### 📌 重点理解：生产者-消费者模式

```cpp
// 为什么用生产者-消费者，而不是直接在回调中处理？

// ❌ 直接在回调中处理
edge_sdk::ErrorCode onMediaFileUpdate(const MediaFile& file) {
    processFile(file);  // 可能耗时 100ms+
    return kOk;
}
// 问题：阻塞 SDK 内部线程，可能导致后续文件丢失

// ✅ 生产者-消费者
edge_sdk::ErrorCode onMediaFileUpdate(const MediaFile& file) {
    fileQueue_.push(file);   // 快速入队
    queueCv_.notify_one();   // 通知消费者
    return kOk;              // 立即返回
}

// 工作线程（消费者）
void execute() {
    while (running_) {
        queueCv_.wait(...);   // 等待新文件
        auto file = fileQueue_.pop();
        processFile(file);    // 耗时处理在这里
    }
}
```

### processFile 完整流程

```cpp
bool MediaFileTask::processFile(const edge_sdk::MediaFile& file,
                                 const std::vector<uint8_t>& imageData) {
    // 1. 保存到本地磁盘（方便 EXIF 解析）
    std::string localFilePath = "./" + file.file_name;
    dumpMediaFile(localFilePath, imageData);

    // 2. 解码图片
    cv::Mat frame = cv::imdecode(imageData, cv::IMREAD_COLOR);

    // 3. ⭐ 解析 EXIF 元数据（GPS、航向、时间）
    auto& imageProcessor = utils::ImageProcessor::getInstance();
    auto exifOpt = imageProcessor.parseExif(localFilePath);

    if (!exifOpt) {
        logger_.warning("EXIF 解析失败，跳过");
        return false;
    }

    // 4. ⭐ 调用 TaskService 进行目标检测
    std::vector<BoundingBox> boundingBoxes;
    bool success = service_->processFrame(frame, config_, boundingBoxes, file.file_name);

    // 5. 更新统计
    stats_.framesProcessed++;
    stats_.detectionsCount += boundingBoxes.size();

    return success;
}
```

### TaskService::processFrame

```cpp
bool TaskService::processFrame(const cv::Mat& frame,
                               const TaskConfig& config,
                               std::vector<BoundingBox>& outBoxes,
                               const std::string& fileName) {
    // 1. ⭐ 目标检测（调用检测器）
    std::vector<BoundingBox> boxes;
    if (!detectObjects(frame, config, boxes)) {
        return false;
    }

    // 2. 过滤：只保留配置中关注的类别
    boxes = filterByEventTypes(boxes, config);

    // 3. 无检测结果，返回
    if (boxes.empty()) {
        outBoxes.clear();
        return true;  // 处理成功，只是没有目标
    }

    // 4. 构建检测事件
    for (const auto& eventType : config.eventTypes) {
        DetectionEvent event = buildEvent(frame, boxes, config, eventType, fileName);

        // 5. ⭐ 发布事件到 MQTT
        publishEvent(event, config.deviceSn);
    }

    outBoxes = boxes;
    return true;
}
```

### detectObjects（工厂 + 策略模式）

```cpp
bool TaskService::detectObjects(const cv::Mat& frame,
                                const TaskConfig& config,
                                std::vector<BoundingBox>& boxes) {
    // 1. ⭐ 工厂模式：根据配置创建检测器
    auto detector = vision::DetectorFactory::createDetector(config.detectorType);

    if (!detector) {
        return false;
    }

    // 2. ⭐ 策略模式：统一接口调用
    return detector->detect(frame, boxes, config.confidenceThreshold);
}
```

```cpp
DetectionEvent TaskService::buildEvent(const cv::Mat& frame,
                                       const std::vector<BoundingBox>& boxes,
                                       const TaskConfig& config,
                                       const EventType& eventType,
                                       const std::string& fileName) {
    DetectionEvent event;

    // 1. 生成唯一 ID
    event.UUID = generateUUID();
    event.taskId = config.taskId;

    // 2. 时间戳
    event.createTime = getCurrentTimeString();

    // 3. ⭐ 图像编码（JPEG + Base64）
    std::vector<uint8_t> jpegBuffer;
    encodeImageToJPEG(frame, 85, jpegBuffer);
    event.picture = encodeBase64(jpegBuffer);
    event.pictureCode = ".jpg";

    // 4. ⭐ GPS 坐标计算（调用 GeoDecodeAPI）
    calculateGPSCoordinates(frame, boxes, event, fileName);

    // 5. 检测框列表
    for (const auto& box : boxes) {
        DetectionPoint point;
        point.x = box.x;
        point.y = box.y;
        point.w = box.w;
        point.h = box.h;
        point.className = box.className;
        point.confidence = box.confidence;
        event.points.push_back(point);
    }

    return event;
}
```

```cpp
    task->onTaskEnd();

// LiveStreamTask 实现
void LiveStreamTask::onTaskEnd() {
    // 直播流任务：立即停止
    stop();
}

// MediaFileTask 实现
void MediaFileTask::onTaskEnd() {
    // 媒体文件任务：仅标记，不停止
    // 因为文件可能还在传输中
    taskEnded_.store(true);

    // 重置超时计时器
    lastFileTime_ = std::chrono::steady_clock::now();

    logger_.info("航线结束，等待文件传输完成（60秒超时）");
}
```

### 监控线程与自动完成

```cpp
void MediaFileTask::monitorLoop() {
    while (running_) {
        std::this_thread::sleep_for(std::chrono::seconds(5));

        // 检查自动完成条件
        if (shouldComplete()) {
            completeTask();
            break;
        }
    }
}

bool MediaFileTask::shouldComplete() {
    // 条件1：航线已结束
    if (!taskEnded_.load()) return false;

    // 条件2：60秒无新文件
    auto elapsed = std::chrono::steady_clock::now() - lastFileTime_;
    return elapsed >= std::chrono::seconds(60);
}

void MediaFileTask::completeTask() {
    // 1. 推送任务分析完成消息
    publishTaskAnalysisResult(true);

    // 2. 清理本地文件
    cleanupFiles();

    // 3. 恢复 DJI 设置
    restoreDjiSettings();
}
```

### 📌 重点理解：为什么 MediaFileTask 不立即停止？

```
问题场景：
1. 无人机航线任务结束，平台发送 device_task_end
2. 但飞机刚返回机场，照片还在下载中
3. 如果立即停止任务，后续照片将无法处理

解决方案：
MediaFileTask 使用 "标记 + 超时" 机制：
- taskEnded_ = true    → 标记航线已结束
- 60秒无新文件        → 认为传输完成
- 两个条件都满足      → 自动完成任务

这就是为什么需要多态：
- LiveStreamTask.onTaskEnd() → 立即 stop()
- MediaFileTask.onTaskEnd()  → 仅设置标志
```
