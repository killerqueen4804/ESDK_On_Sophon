### 2. MQTT Broker 配置

**配置文件**: `config/config.json`

```json
{
  "mqtt": {
    "broker": "tcp://jiaoyujidi.work:1883",
    "client_id": "analysis_device_WRSE7002",
    "topics": {
      "services_down": "thing/product/{device_sn}/services",
      "services_reply": "thing/product/{device_sn}/services_reply",
      "events_up": "thing/product/{device_sn}/events",
      "event_push": "drone/{device_sn}/info/event"
    }
  },
  "device": {
    "analysis_sn": "analysis_device_WRSE7002"
  }
}
```

**验证 MQTT 连接**:

```bash
# 使用 mosquitto_sub 监听所有主题
mosquitto_sub -h jiaoyujidi.work -p 1883 -t '#' -v

# 或只监听我们的设备
mosquitto_sub -h jiaoyujidi.work -p 1883 \
  -t 'thing/product/analysis_device_WRSE7002/#' \
  -t 'drone/analysis_device_WRSE7002/#' \
  -v
```

### 3. 准备测试数据

#### 方案 A: 使用本地图片（推荐）

**准备测试图片**:

```bash
# 在算能服务器上创建测试目录
mkdir -p /data/test_media

# 复制一些带 EXIF 的图片
# （可以从手机拍摄的照片，包含 GPS 信息）
cp ~/sample_images/*.jpg /data/test_media/
```

**图片要求**:

- ✅ 格式: JPG/JPEG
- ✅ 包含 EXIF 信息（拍摄时间、GPS 坐标）
- ✅ 清晰可见的物体（人、车、动物等）
- ✅ 文件大小: 1-10 MB

#### 方案 B: 使用 DJI MediaManager（真实场景）

需要 DJI 无人机连接和 DJI SDK 配置。

### Step 2: 发送启动任务消息

**使用 mosquitto_pub 发送 MQTT 消息**:

```bash
# 构建启动任务的 JSON 消息
cat > /tmp/start_task.json <<'EOF'
{
  "method": "device_algorithm_enable",
  "data": {
    "taskID": "test_task_001",
    "algorithmRepoID": 1,
    "algorithmName": "COCO目标检测",
    "dataSource": "file",
    "baseFolder": "/data/test_media",
    "confidence": 0.25,
    "reportInterval": 10,
    "types": [
      {
        "id": 1,
        "mainType": 1,
        "subType": 1,
        "name": "person",
        "classes": ["person"]
      },
      {
        "id": 2,
        "mainType": 1,
        "subType": 2,
        "name": "vehicle",
        "classes": ["car", "truck", "bus"]
      }
    ]
  }
}
EOF

# 发送启动消息
mosquitto_pub -h jiaoyujidi.work -p 1883 \
  -t 'thing/product/analysis_device_WRSE7002/services' \
  -f /tmp/start_task.json
```

**预期程序输出**:


## 🐛 常见问题排查

### 问题 1: MQTT 连接失败

**现象**:

```
[ERROR] MQTT 连接失败: Connection refused
```

**排查**:

```bash
# 1. 检查 Broker 是否可达
ping jiaoyujidi.work

# 2. 检查端口是否开放
telnet jiaoyujidi.work 1883

# 3. 检查配置文件
cat config/config.json | grep broker
```

---

### 问题 2: 没有收到文件通知

**现象**:

```
# 程序没有输出 "收到媒体文件更新通知"
```

**排查**:

```bash
# 1. 检查 MediaFilesObserver 是否注册
grep "注册 MediaFilesObserver" logs/*.log

# 2. 检查文件路径
ls -lh /data/dji_media/test_task_001/

# 3. 检查 DJI SDK 是否正常
# (如果使用 DJI MediaManager)
```

---

### 问题 3: 检测失败

**现象**:

```
[ERROR] 检测执行失败: Model not loaded
```

**排查**:

```bash
# 1. 检查模型文件
ls -lh /data/Edge-SDK/models/PaddleDetection/ppyoloe_crn_m_300e_coco_289.bmodel

# 2. 检查检测器初始化
grep "PPYoloeDetector" logs/*.log

# 3. 检查算能 TPU 状态
bm-smi
```

---

### 问题 4: MQTT 消息未发送

**现象**:

```
[WARNING] ⚠️ 任务分析结果发布失败（已缓存，等待重试）
```

**排查**:

```bash
# 1. 检查 EventCache 日志
grep "EventCache" logs/*.log

# 2. 检查 MqttClient 状态
grep "MQTT" logs/*.log | tail -20

# 3. 手动测试 MQTT 发布
mosquitto_pub -h jiaoyujidi.work -p 1883 \
  -t 'test/topic' -m '{"test": "message"}'
```

| 指标             | 目标值   | 说明                   |
| ---------------- | -------- | ---------------------- |
| **文件处理延迟** | < 2 秒   | 从文件到达到开始处理   |
