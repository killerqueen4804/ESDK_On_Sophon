## 📋 改动概述

本次更新重构了事件推送接口,适配云端新的 API 规范:

### 核心变更

1. ✅ **字段名更新**: `taskId (string)` → `taskID (int)`, `mainType` → `main_type`
2. ✅ **嵌套结构**: 新增 `result.image` 和 `result.objects`
3. ✅ **可视化图片**: `resultImage` 包含绘制了检测框/分割轮廓的 Base64 图片
4. ✅ **GPS 位置**: 每个 `bbox` 和 `mask` 点都包含 GPS 坐标
5. ✅ **本地保存**: 分割可视化图片自动保存到 `/data/Edge-SDK/results/seg_vis/`

## 🐛 常见问题排查

### 问题 1: SAM2 未启用

**症状**:

```
❌ [分割任务] SAM2 未启用,无法执行分割任务
```

**解决**:
检查 `config/config.json`:

```json
{
  "segmentation": {
    "sam2": {
      "enabled": true, // 必须为 true
      "encoder_model_path": "/data/models/sam2_encoder_bm1684x_f32.bmodel",
      "decoder_model_path": "/data/models/sam2_decoder_bm1684x_f32.bmodel"
    }
  }
}
```

## 📊 性能监控

### Base64 编码大小

- **目标检测**: ~200-400 KB (JPEG) → ~270-530 KB (Base64)
- **语义分割**: ~300-600 KB (JPEG) → ~400-800 KB (Base64)

**优化建议**:

- JPEG 质量可调整 (当前 85%): `encodeImageToJPEG(frame, 85, buffer)`
- 如果 JSON 过大,可以降低质量到 75-80%

---

### 轮廓点数量

- **原始轮廓**: 可能有数百个点
- **简化后**: 使用 `cv::approxPolyDP(epsilon=2.0)` 简化到 20-100 个点

**优化建议**:

- 如果 mask 数组过大,可以增大 epsilon 值 (如 3.0 或 5.0)
- 在 `buildSegmentationEvent()` 中修改:
  ```cpp
  cv::approxPolyDP(result.contours, approx, 3.0, true);  // 更激进的简化
  ```
