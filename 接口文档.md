## 事件推送

---

**Topic:** drone/{device_sn}/info/event
**Direction:** up
**Data:**

| Column           | Name         | Type   | constraint                                                                                                                         | Description                           |
| ---------------- | ------------ | ------ | ---------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------- |
| `UUID`           | 事件 UUID    | string |                                                                                                                                    |
| `taskID`         | 任务 ID      | number |                                                                                                                                    | 任务下发时的任务 ID                   |
| `eventType`      | 事件类型     | number | <br> 200004: 垃圾倾倒 <br> 200005:河面污染物 <br> 200006：三大堆 <br> 200007：人车检测 <br> 200008：船只检测 <br> 200009：分割测试 | 算法检测到的事件类型                  |
| `main_type`      | 算法主类型   | number | 100000:目标检测 <br> 100001:语义分割                                                                                               | 算法主类型                            |
| `createTime`     | 事件发生时间 | string |                                                                                                                                    |
| `eventDescribe`  | 事件描述     | string |                                                                                                                                    |
| `longitude`      | 经度         | float  |                                                                                                                                    | 图片拍摄时无人机经度                  |
| `latitude`       | 纬度         | float  |                                                                                                                                    | 图片拍摄时无人机纬度                  |
| `fileName`       | 文件名称     | string |                                                                                                                                    | 图片文件名称，包含后缀名,如：test.jpg |
| `result`         | struct       |        | 结果                                                                                                                               |
| >>`image`        | String       |        | 结果图片， base64                                                                                                                  |
| >>`objects`      | array        |        | 识别结果列表                                                                                                                       |
| >>>>`label`      | string       |        | 类别标签                                                                                                                           |
| >>>>`bbox`       | array        |        | 目标检测框: (x, y, w, h)                                                                                                           |
| >>>>>>`x`        | int          |        | 图片中检测到的目标框左上角 x 坐标                                                                                                  |
| >>>>>>`y`        | int          |        | 图片中检测到的目标框左上角 y 坐标                                                                                                  |
| >>>>>>`w`        | int          |        | 图片中检测到的目标框宽度                                                                                                           |
| >>>>>>`h`        | int          |        | 图片中检测到的目标框高度                                                                                                           |
| >>>>>>`location` | struct       |        | 图片中检测到的目标框中心点实际经纬度                                                                                               |
| >>>>>>>>`lon`    | float        |        | 图片中检测到的目标框中心点经度                                                                                                     |
| >>>>>>>>`lat`    | float        |        | 图片中检测到的目标框中心点纬度                                                                                                     |
| >>>>`mask`       | array        |        | 分割结果轮廓点列表                                                                                                                 |
| >>>>>>`x`        | int          |        | 分割结果轮廓点 x 坐标                                                                                                              |
| >>>>>>`y`        | int          |        | 分割结果轮廓点 y 坐标                                                                                                              |
| >>>>>>`location` | struct       |        | 分割结果轮廓点实际经纬度                                                                                                           |
| >>>>>>>>`lon`    | float        |        | 分割结果轮廓点经度                                                                                                                 |
| >>>>>>>>`lat`    | float        |        | 分割结果轮廓点纬度                                                                                                                 |

# 算法同步

## Path

MQTT

## Content

## 算法同步

---

**Topic:** thing/product/{device_sn}/services
**Direction:** down
**Method:** device_algorithm_sync
**Data:**
Column | Name | Type | constraint | Description
---------|----------|---------|----------|---------
algorithm_list | 算法仓列表 | array | | 算法仓列表
\>>id | 算法仓 ID | number | | 算法仓 ID，唯一标识算法仓
\>>name | 算法仓名称 | string | |
\>>version | 算法仓版本号 | string | |
\>>type | 算法类型 | array | | 算法类型
\>>>>id | 算法 ID | number | 200004: 垃圾倾倒 <br> 200005:河面污染物 <br> 200006：三大堆 <br> 200007：人车检测 <br> 200008：分割测试 | 算法 ID
\>>>>name | 算法名称 | string | | 算法名称
\>>>>class | 标签 | array | | 标签列表, eg["car", "person"]
\>>>>main_type | 算法主类型 | number | 100000:目标检测 <br> 100001:语义分割 | 算法主类型
\>>url | 下载地址 | string | | 算法包下载地址

示例：

```json
{
  "algorithm_list": [
    {
      "id": 1234,
      "name": "智慧巡检算法仓",
      "version": "v1.0",
      "url": "http://example.com/algorithm_package_1.zip",
      "type": [
        {
          "id": 200004,
          "name": "垃圾倾倒",
          "class": ["car", "person"],
          "main_type": 100000
        }
      ]
    }
  ],
  "method": "device_algorithm_sync"
}
```

---

# 算法启用

## Path

MQTT

## Content

## 算法启用

---

任务下发后启用算法分析
**Topic:** thing/product/{device_sn}/services
**Direction:** down
**Method:** device_algorithm_enable
**Data:**
Column | Name | Type | constraint | Description
---------|----------|---------|----------|---------
id | 算法仓 ID | number | | 算法仓 ID，唯一标识算法仓
name | 算法仓名称 | string | |
version | 算法仓版本号 | string | |
type | 算法类型 | array | 200004: 垃圾倾倒 <br> 200005:河面污染物 <br> 200006：三大堆 <br> 200007：人车检测 | 算法类型
\>>id | 算法 ID | number | | 算法 ID
\>>name | 算法名称 | string | | 算法名称
\>>class | 标签 | array | | 标签列表, eg["car", "person"]
\>>main_type | 算法主类型 | number | 100000:目标检测 <br> 100001:语义分割 | 算法主类型
taskID | 任务 ID | number | | 任务下发时的任务 ID
source | 算法分析类型 | int | 0：视频流分析 <br> 1：图片分析 |
display | 显示分析结果 | int | 0: 显示 <br> 1: 不显示 | 当分析视频流时，是否显示分析结果，type 为 0 时有效
airtransfer | 空中回传 | int | 0: 不回传 <br> 1: 回传 | 是否在飞行过程中拍照的照片快速回传至云端，type 为 1 时有效

示例：

```json
{
  "id": 1234,
  "name": "智慧巡检算法仓",
  "version": "v1.0",
  "type": [
    {
      "id": 200004,
      "name": "垃圾倾倒",
      "class": ["car", "person"],
      "main_type": 100000
    }
  ],
  "taskID": 1234,
  "source": 0,
  "display": 0,
  "airtransfer": 0,
  "method": "device_algorithm_enable"
}
```

## 算法启用返回结果

---

**Topic:** thing/product/{device_sn}/services_reply
**Direction:** up
**Method:** device_algorithm_enable
**Data:**

result | 返回码 | int | 0: 成功 <br> 255：未知错误 | 非 0 代表错误
示例：

```json

  "method": "device_algorithm_enable"
}
```
